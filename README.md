# ぽけぷりんの公式サイト

既存の公式ページを `original.html` にそのまま保持し、`index.html` の入口から表示します。右下の「ぽけの遊び場へ」から新しいコンテンツを開けます。直接の入口は `play.html` です。

## ぽけの遊び場

- 日本時間1日1回の訪問記録・日数による段階解放
- 増える褒めボタン、30種類の速報、日替わりのお告げ・ご機嫌
- 称号、ぽけからの手紙、ふざけた設定、日替わり業務、謎の統計
- ジョーク規約、アップデート履歴、節目の表彰式・表彰状ダウンロード
- 謎の荷物、コレクション、事件アルバム、深夜・ロゴ・合言葉の隠し実績
- 100日目の休憩室、200日目のエンディング、300日以降の感謝状
- 未来の段階の体験モード。実際の進捗や全体集計には反映しません。
- JSONで進捗のバックアップ・復元
- 全セリフは標準語

ブラウザ内保存でそのまま動きます。サーバー保存・全員参加の応援集計は [server/README.md](server/README.md) の設定が必要です。

## 確認

```sh
node --test tests/*.test.mjs
node --check assets/play.mjs
node --check server/worker.mjs
```

静的ファイルをHTTPサーバーから配信してください。ES Modulesを使うので `file://` で直接開くことは想定していません。

既存の約14MBのページはGitHub連携で本文を取得できなかったため、元のblobをそのまま `original.html` として保持しています。トップはiframeで元ページを表示し、新しい入口ボタンを重ねます。元ページの直接URLは `/original.html` になります。既存ページのブラウザ表示・外部リンク・ハッシュリンクへの影響は、マージ前に確認してください。
